# FunItems

Плагин Spigot/Paper 1.21.x с предметами в стиле FunTime: трапка, пласт, эффекты, тотемы-варианты, мечи, броня и PvP-расходники.

## Команды модерации

- `/funitems list` — список ID предметов.
- `/funitems give <игрок> <id> [количество]` — выдать предмет.
- `/funitems reload` — перезагрузить config.yml.
- Алиас: `/fi`

Доступ ограничен permission `funitems.admin` (по умолчанию только OP). Для использования специальных активируемых предметов есть `funitems.use`.

## Сборка через GitHub Actions

1. Создай пустой репозиторий на GitHub.
2. Распакуй содержимое этого архива и загрузи файлы в корень репозитория (папка `src`, `pom.xml`, `.github` и т.д.; не загружай внешнюю папку-обёртку `FunItems`).
3. Сделай commit/push в `main` или `master`.
4. Открой вкладку **Actions** → **Build FunItems**. После успешной сборки скачай артефакт **FunItems-plugin** — внутри будет `FunItems.jar`.

Локальная сборка: `mvn clean package` с установленным JDK 21 и Maven.

## Примечание

Обычные мечи, броня, тотемы и расходники выдаются как подписанные предметы с отображаемым именем и описанием. Активные механики ПКМ реализованы для специальных предметов, перечисленных в `ItemListener`; для добавления новых способностей нужно реализовать обработчик использования.
